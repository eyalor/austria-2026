## עובד בלי אינטרנט

באזורים מסוימים בהרי האלפים או בתוך הקניונים ייתכן שאין קליטה. `sw.js` שומר במכשיר את כל הדפים, הנתונים והאיורים בביקור הראשון, והאתר נפתח במלואו גם בלי רשת.

* **הקבצים הקבועים** נטענים מהמטמון קודם — פתיחה מיידית.
* **`data/*.json`** נטענים מהרשת קודם ונופלים למטמון.
* **התחזית האחרונה נשמרת** ומוצגת כשאין רשת.
* **`index.html` עצמו נטען מהרשת קודם** ונופל למטמון רק כשאין חיבור.
